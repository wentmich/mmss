# mmss
MMSS GR Course Python module

This repository contains an introduction to coding in Python aimed at advanced high school students with an interest
in General Relativity. The directory contains three worksheets listed below along with the level of GR familiarity it would
take to appreciate them.


intro-python.ipynb --- this worksheet requires no knowledge of GR and is simply an introduction
                       to python. it covers the basics of syntax, output statements, if/else
                       statements, for and while loops, package imports, and function definitions.

schorbits-worksheet.ipynb --- this worksheet is adapted from a Mathematica notebook written by 
			      Daniel Mayerson in which the orbits of a particle in a Schwarzschild
                              metric are calculated and the precesion of Mercury is predicted.
			      this workshieeet is best completed with a knowledge of Newtonian
			      gravity and some familiarity with GR.

lensing-mhcw.ipynb --- this program requires no knowledge of GR to run, but an appreciation for
                       the concept of gravitational lensing will make it actually interesting. The
 		       notebook is mainly just for plotting the lensing of a (very simplified)
                       galaxy by a black hole.
